# Harness Tool Coverage

ツール環境の完全網羅と適切な使い分けを定義する。

## ツールマップ
- **Unity Editor制御**: `unityMCP:manage_editor` (play, stop, pause)
- **ログ・コンソール診断**: `unityMCP:read_console` (get, clear)
- **アセット・スクリプト更新**: `unityMCP:refresh_unity`
- **高精度コード編集**: `replace_file_content`, `multi_replace_file_content`
- **バージョン管理・システム操作**: `run_command` (git, find, build)
