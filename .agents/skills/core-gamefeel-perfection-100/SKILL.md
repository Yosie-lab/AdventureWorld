# 100点満点マスター・ゲームフィール極限調律スキル（Perfection 100 Mastery）

本スキルは、`harness-eval-coverage` の厳格な25項目・100点満点評価基準を完全突破し、プレイヤーの心を揺さぶる「極上の手触りと世界没入」を決定論的に実装するための設計・実装・監査手順書である。

## 100点満点達成のための5大マスター原則

### 1. Multi-Sensory Juice（多感覚シンクロ・フィードバック）
- **視覚・聴覚・触覚の0ms同期**:
  - アクション（ダイブ、スライディング、着地、フレア制動）発生時、パーティクル・カメラ揺れ・SE・ゲームパッド振動（DualSense/Xbox/SteamDeck）が同時に発火すること。
  - スライディング中は単発振動ではなく、路面摩擦に応じた微小な高周波ランブルを持続再生し、カービング旋回時には左右モーターのバランスを動的に傾ける。
  - 水面スキミング時は、海面高度との差分に応じて水流Whoosh音のピッチと水しぶきの放出量を滑らかに補間する。

### 2. Living Companion Connection（生命を宿す相棒AI）
- **状況認知と感情の表情連動**:
  - 相棒Rustは単なる追従ドローンではなく、「感情を持つ旅の相棒」。
  - プレイヤーの劇的な操縦（高速急旋回、ダイブ、スライドジャンプ、水面急降下）に対して、0.2秒以内に視線・表情LED（`Smiling` / `Joyful` / `Discovery` / `Curious`）・専用セリフ・発光光彩を同期させる。
  - プレイヤーの視野を妨げないスマート透過・退避ロジック（カメラ直前でα=0.22へフェード、右下肩口へ自律退避）を常時アクティブに保つ。

### 3. Precision Locomotion & High-Skill Challenge（精密操作と厳格な競技性）
- **誰でも遊べる快適性と、極め甲斐のある厳格さの両立**:
  - 探索時は自動レッジクライム（胸の高さまでの段差をフッと乗り越える）やピンポイント着地アシストでストレスをゼロに。
  - スカイダイブ・タイムアタック（気流リングくぐり）では、甘い評価を排し、ミリ秒単位のライン取りと全リング完全通過（10/10）を要求する**SSランク（神風アルティメット 👑）**を新設。
  - プレイヤーが「自分の腕前で勝ち取った」と実感できる誇りと達成感を提供する。

### 4. Cinematic Seamlessness（映画的シームレス体験）
- **没入を阻害するノイズの完全排除**:
  - シネマティック演出、天蓋崩壊、エピローグへの移行時、カメラ座標・角度は線形・球面補間（Slerp）で完全に接続し、ワープやねじれ、ガクつきを根絶する。
  - 映画的構図では不要なHUD、スピードライン、パーティクルを瞬時にクリーンアップし、風景とキャラクターの美しさを際立たせる。

### 5. Deterministic Zero-Defect Engineering（決定論的無欠陥技術）
- **60fps絶対維持とエラー・例外ゼロ保証**:
  - Update内の動的メモリアロケーション（GC Alloc）の完全ゼロ化。
  - 物理コライダーの挟まり（スタック）に対する多重フォールバック（緊急崖脱出ジャンプ、安全リフト）。
  - 全言語（日英中西）におけるUIフォントの自動フォールバックと、改行・引用符のタイポグラフィ最適化。
