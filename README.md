# Rust & Float

AdventureWorld とは別の Unity プロジェクトです。

- Unity: 6000.5.8f1（Unity 6）
- メインシーン: `Assets/RustAndFloat/Scenes/RustAndFloat.unity`
- 地形: `Assets/RustAndFloat/Terrain/IslandTerrain.asset`

## 開き方

1. Unity Hub を開く
2. **Add** → このフォルダ `RustAndFloat` を選ぶ
3. Unity 6000.5.8f1 で開く（初回は Library 生成で数分かかります）
4. メニュー **RustAndFloat → Open Main Scene**

AdventureWorld のプロジェクト（`Unity project`）は変更不要・別物です。
